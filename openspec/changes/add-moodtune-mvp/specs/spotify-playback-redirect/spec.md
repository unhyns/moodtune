## Purpose

Lets the user move from a recommendation straight into Spotify playback, keeping playback itself entirely inside Spotify rather than building in-app playback.

## ADDED Requirements

### Requirement: Redirect to Spotify for Playback
The system SHALL let the user open the recommended track in Spotify, in the app or on the web, directly from the recommendation result.

#### Scenario: User opens the recommended track
- **WHEN** the user taps the recommended track card
- **THEN** the system SHALL open the corresponding Spotify track in a new tab or via an app deep link
