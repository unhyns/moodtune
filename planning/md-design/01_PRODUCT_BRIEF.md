# 01. Product Brief — MoodTune (무드튠)

> Scope: 문제, 사용자, 가치, 범위만 다룹니다.
> 다루지 않음: 기능 상세/인수조건(02), 화면·컴포넌트(03), 기술 구조(04), 일정·QA(05).

## 서비스 개요
- **서비스명**: MoodTune (무드튠)
- **슬로건**: 나만의 선곡 파트너 / 내 손 안의 DJ, 무드튠

## 1. 문제 정의
- 스트리밍 서비스에 곡은 넘치지만, 정작 "지금 이 순간에 뭘 들을지" 고르는 데 매번 시간과 고민이 든다 (선택 피로).
- 기존 추천 시스템은 신곡·인기곡 위주라, 사용자가 이미 만들어둔 플레이리스트나 취향은 잘 활용되지 않는다.
- 기분·날씨·상황(출근길, 산책, 카페 등)에 따라 듣고 싶은 음악이 확연히 다른데, 이 세 가지를 조합해서 골라주는 서비스는 마땅치 않다.
- 특히 외출하면서 짧은 시간 안에 "오늘 뭐 듣지"를 정해야 하는 순간의 니즈가 해결되지 않고 있다.

## 2. 타겟 사용자
- Spotify를 일상적으로 사용하며, 출근길·산책·카페 등 짧은 이동/전환 순간에 음악을 트는 학생·2030.
- 이미 자신만의 플레이리스트나 좋아요한 곡이 어느 정도 쌓여 있어, 새 음악 발굴보다 "내 취향 안에서 지금 맞는 곡"을 빠르게 고르고 싶은 사용자.

## 3. 핵심 가치
- 새로운 곡을 발굴해주는 서비스가 아니라, **이미 가진 라이브러리 안에서** 지금 상황에 가장 잘 맞는 곡/플레이리스트를 빠르게 찾아준다.
- **기분 · 날씨 · 상황** 세 가지 맥락을 함께 고려해 추천의 정확도와 개인화 수준을 높인다.
- **퀵리플라이 버튼 중심**의 가벼운 인터랙션으로, 고민 없이 바로 쓰는 일상 습관형 서비스를 지향한다.

## 4. 범위

### In Scope — 핵심 기능
1. **Spotify 계정 연동**: OAuth 로그인 후 내 플레이리스트·곡 목록 불러오기
2. **날씨 자동 반영**: 위치 기반으로 현재 날씨를 자동 조회, 별도 입력 없이 추천에 반영
3. **기분·상황 입력**: 퀵리플라이 버튼(기본) + 자연어 텍스트 입력(옵션)
4. **AI 맞춤 추천**: 실제 라이브러리 + 현재 기분·날씨·상황을 종합해 곡/플레이리스트 제시
5. **Spotify로 바로 이동해 재생**: 추천 결과 클릭 시 Spotify 앱(또는 웹)으로 연결

### Out of Scope
- 신규/미보유 음악 발굴 추천 (항상 사용자 라이브러리 내에서만 추천)
- 결제/구독 기능
- 소셜 공유, 다중 사용자 협업 기능
- 인앱 재생 (항상 Spotify로 리다이렉트)
- 오프라인 모드
